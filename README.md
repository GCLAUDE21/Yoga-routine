# 🧘 Yoga Routine

Application web de minuterie pour routines de yoga et d'exercices.

Projet réalisé en cours de formation développeur web.

🔗 [Voir le projet en ligne](https://gclaude21.github.io/Yoga-routine/)

---

## Fonctionnalités

- Configurer la durée de chaque exercice (en minutes)
- Réordonner les exercices
- Supprimer un exercice
- Lancer le compte à rebours automatique
- Passage automatique à l'exercice suivant avec signal sonore
- Sauvegarde de la configuration via `localStorage`

## Technologies

- HTML / CSS
- JavaScript vanilla (ES6)
- LocalStorage


## Concepts JS abordés

- Classe ES6 et `this`
- Récursivité avec `setTimeout`
- Manipulation de tableaux (`map`, `filter`)
- Manipulation du DOM
- Stockage local (`localStorage`)
